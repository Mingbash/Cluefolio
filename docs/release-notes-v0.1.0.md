# Cluefolio v0.1.0

- 在 Codex Desktop 对话里打开笔记卡片，勾选并开始。Codex 使用你自己的登录与模型接续工作。
- 从小红书精选笔记生成版本化 Context，提炼核心主张与公开公理，区分上游原作与创作者贡献，保留图片页码和视频时间码。
- 本地工作台支持来源追踪、归因与作者修正、证据检索、验收检查和 ZIP 导出。
- 任务中断后使用原任务编号继续。已接受的模型步骤和已清洗的本地材料可以复用。

首版支持 Apple Silicon Mac 上的 Codex Desktop。需要自己的 Codex 登录和连接 Chrome 的 OpenCLI。其他 Agent 提供实验性配置。源码包提供 MIT 许可证与安装说明，导入的笔记和媒体由各用户在本机管理。

## rc4 更新

- 首页改为“按问题找原文”，搜索结果紧随问题输入框，相关原文更容易找到。
- 项目选择移入各分栏，各自记住当前项目；新建项目使用独立页面。
- 统一红白界面与日常用语，删除装饰性编号标题，补齐空状态和恢复提示。
- 源码 ZIP 保留 Mac 启动器执行权限，新增逐文件清单与 SHA-256 校验文件。
- 增加干净源码包测试和贡献说明，公开列出输入预算、评估标注及支持范围的限制。

本版本是预发布候选，不代表原定验收全部完成。见 [发布边界](release-readiness.md)。

## 评测更新

独立 LLM 对 57 项样本逐项复核，发现 8 项原标注需要修正、2 项证据不足。按修正后的可判样本重算，开发集检索 Recall@10 为 92.9%，留出集为 100%。原始复核材料留在本机，不随开源源码发布。该评测不是人工专家验收。
