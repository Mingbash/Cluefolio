# 验收说明

正式支持范围为 Apple Silicon Mac 上的 Codex Desktop。其他 Agent 的本机配置为实验用途。工作台仅在本机运行。

`npm test` 在干净数据目录覆盖来源归因、证据映射、笔记选择、工作台接口和桌面任务断点。桌面集成测试启动真实的本机 MCP 进程，用模拟笔记和模型回复复现进程被强制结束后的接续。

真实平台的专项验收覆盖对话内勾选、点击后同一对话接续、浏览器桥接断开与恢复、图片页码和视频时间码、Context 校验及导出。公开源码包使用虚构或脱敏材料。安装机器仍需具备可用的小红书会话和自己的 Codex 登录。

`npm run evaluate:context -- <本机标注文件>` 量化前十条证据的召回率、原创结论误判率和上游原作推荐准确率。标注 JSON 包含 `contextId`、`version`、`retrieval`（每个问题的相关观点分组）、`originals`（需要保护的观点 ID）和 `sources`（观点 ID、可接受原作 URL 和判定理由）。同一组内的证据可以互相替代。没有原作候选的结果不计作命中。应保留正例覆盖率及样本规模。

## 已测样本与限制

私有真实材料上的 57 项标注由独立 LLM 逐项复核：47 项同意、8 项不同意、2 项证据不足。检索标签中 4 个有争议的问题删去了不能完整回答问题的相关组；3 条同作者后发笔记的自我复用不再计为该笔记的新原创贡献；2 条证据不足样本不计入通过数；一条上游来源改用实际页面地址。

按修正后的标签重新计算，14 个开发问题的 Recall@10 为 92.9%，10 个留出问题为 100%；19 条保留的原创贡献样本中纯搬运误判为 0。9 个来源场景含 4 个原作正例、5 个背景负例，原作正例全部命中，推荐精确率为 100%。这些数值只适用于该私有语料及这组标签。评审由 LLM 执行，视频和图片判断依赖本机提取文本，不能称为独立人类专家复标。私有原文和逐项评审文件不进入公开包。

任务恢复测试覆盖跨进程保留累计输入预算及发送前拒绝超额材料。该预算只覆盖 Cluefolio 可观察和估算的输入，不能约束宿主额外加入的全部上下文。检索采用全文索引与确定性排序；人工更正影响检索、MCP 和导出，不自动重写已生成的主要观点。完整发布边界见 [候选版本说明](release-readiness.md)。
