# v0.1.0-rc4 发布边界

本候选同步了新版红白工作台与全部界面文案：首页按问题找原文，各分栏独立选择和记住项目，新建项目单独展示；原有编号标题已移除。没有更改本地用户数据或已有知识库。

## 可交付范围

- Apple Silicon Mac、Node.js 24、Codex Desktop，以及用户自己的模型与浏览器登录。
- 对话内选择笔记、启动任务、遇到阻塞暂停，并以原任务编号恢复。
- 文字、图文和视频材料处理，带出处的知识库、检索、创作者贡献与本地导出。
- 本地网页备用入口；其他 Agent 仅提供实验性配置。

## 已确认的预算范围与待完成验收

用户已确认不要求对 Codex 整段会话的输入实行严格封顶。Cluefolio 仍对自己投递的材料使用跨续跑累计预算；Codex 自行加入的系统提示、聊天历史和搜索结果不在这一预算内，CLI 的实际使用量在运行后核账。此项不再作为发布阻塞。

**独立 LLM 复核已完成。** 57 项中，47 项同意、8 项不同意、2 项证据不足。已按复核结果修正评测标签并重算：开发集 14 题 Recall@10 为 92.9%，留出集 10 题为 100%；保留的 19 条原创贡献样本中纯搬运误判为 0；4 个原作正例全部命中，来源推荐精确率为 100%。两条证据不足样本不计入通过数。该结果是 LLM 评审，不是独立人工或融资专家的判断；真实领域准确率仍需更多样本验证。私有复核材料不会进入公开源码包。

## 发布方法

运行 `npm run release:candidate`，得到源码 ZIP、SHA-256 校验文件及包内逐文件清单。发布前应从 ZIP 解压到新目录，运行 `npm ci`、`npm test`、`npm run build`，并启动空工作台。Mac 启动器的执行权限随 ZIP 保存。

**首次公开仓库必须使用该干净快照建立新 Git 历史。** 开发工作区含私人材料的记录与历史文档；不要直接推送开发仓库历史。发布脚本仅复制允许公开的代码、测试和文档，排除本机数据、媒体、环境配置和既有 Git 历史，并扫描常见凭据及私人绝对路径。扫描不能代替对新增文件的审查。

公开仓库为 [Mingbash/Cluefolio](https://github.com/Mingbash/Cluefolio)。已从干净快照建立新历史并推送，GitHub 的 macOS CI 已完成依赖安装、38 项测试、构建与源码打包。仓库的公开代码不含本机私有语料。公开发布说明会保留独立 LLM 评测的范围和限制。

源码使用 MIT；源码许可不覆盖用户导入的笔记和媒体。完整 Context ZIP 用于用户本地备份，不应随源码发布。
